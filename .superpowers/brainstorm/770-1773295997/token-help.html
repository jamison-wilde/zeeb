Format String Token Reference — How should it appear?

The token reference needs to be visible when editing format strings, showing all available tokens with descriptions

A

Inline below each format input

A collapsible "Show tokens" link beneath each format input that expands a compact reference table. Always near the input being edited. Repeated for each format field.

B

Fixed reference panel on the right

The Formatting section splits into two columns: format inputs on the left, a permanent token reference on the right. Always visible while editing any format. Tokens are clickable to insert into the focused input.

C

Autocomplete dropdown in the input

Typing < in a format input opens an autocomplete dropdown showing matching tokens with descriptions. Like IDE autocomplete. No separate reference panel needed — discovery happens through typing.
